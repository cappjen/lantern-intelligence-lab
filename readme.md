# Lantern Intelligence Lab

A static launch site for Lantern Intelligence Lab.

## Publish in minutes

### Netlify Drop
1. Unzip this folder.
2. Visit Netlify Drop.
3. Drag the entire `lantern-intelligence-lab` folder onto the page.
4. Netlify will immediately assign a public URL.

### GitHub Pages
1. Create a new public GitHub repository.
2. Upload `index.html`, `styles.css`, and `script.js` to the repository root.
3. Open Settings → Pages.
4. Choose “Deploy from a branch,” then select `main` and `/root`.

### Vercel
1. Create a GitHub repository containing these files.
2. Import the repository into Vercel.
3. Keep the default settings and deploy.

No build command or framework is required.
